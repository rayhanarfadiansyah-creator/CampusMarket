# CampusMarket

CampusMarket adalah website marketplace kuliner yang ditujukan untuk mahasiswa agar dapat melihat produk makanan dan melakukan pemesanan dengan mudah.

## Fitur Utama

- Menampilkan katalog produk makanan.
- Pencarian dan filter produk.
- Pemesanan melalui WhatsApp.
- Pengelolaan stok produk.
- Panel admin.
- Integrasi dengan Google Apps Script.

## Teknologi

- HTML
- CSS
- JavaScript
- Node.js
- Google Apps Script

## Cara Menjalankan

1. Pastikan Node.js sudah terpasang.
2. Buka terminal di folder project.
3. Jalankan server sesuai konfigurasi project.
4. Buka alamat lokal yang ditampilkan oleh server di browser.

## Tujuan Project

Project ini dikembangkan sebagai bagian dari tugas Studi Independen untuk mempraktikkan pengembangan website dan penggunaan Git untuk version control.
